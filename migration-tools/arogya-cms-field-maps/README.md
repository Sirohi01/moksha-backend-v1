# Arogya CMS Field Maps

This directory contains mappings for migrating Arogya CMS content models (Phase 10) into the unified Moksha schema.

## Index

1. **[hero-field-map.md](./hero-field-map.md)**
   Backs the main Hero banner section on the public homepage.
2. **[messages-field-map.md](./messages-field-map.md)**
   Backs the Chairman's and Founder's message sections on the public homepage / about page.
3. **[faq-field-map.md](./faq-field-map.md)**
   Backs the Frequently Asked Questions section and its settings.
4. **[glimpse-field-map.md](./glimpse-field-map.md)**
   Backs the "Glimpses" past event gallery, videos, and statistics counters.
5. **[global-voices-field-map.md](./global-voices-field-map.md)**
   Backs the "Global Voices" section featuring international healthcare speakers and related stats.
6. **[partners-field-map.md](./partners-field-map.md)**
   Backs the Partners & Associates section, categorizing sponsors and supporters.
7. **[speakers-field-map.md](./speakers-field-map.md)**
   Backs the various speaker grids (Eminent, Expert, Previous, Organising Committee, etc.) across the site.
8. **[seo-social-field-map.md](./seo-social-field-map.md)**
   Backs the page-specific SEO metadata (title, meta, open graph) and global social media links.
9. **[settings-field-map.md](./settings-field-map.md)**
   Backs the global site settings, including headers, footers, contact info, marquees, and various global flags.
